# Dovisha Technology Website

Static company website prepared for GitHub Pages.

## Before publishing
1. Replace `YOUR-EMAIL@DOMAIN.COM` in `index.html` with the official Dovisha Technology email.
2. Add your final logo/favicon when available.
3. Update company address, phone, and social links once finalized.

## GitHub Pages
Upload these files to the root of your repository, then open **Settings > Pages** and deploy from the `main` branch/root folder.
